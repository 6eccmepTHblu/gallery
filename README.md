# Gallery

Просмотрщик и сортировщик изображений для Windows 11, выросший в мастерскую для
комиксов: листаешь папку, одним хоткеем откладываешь нужное в целевую папку, а на
любой странице можешь распознать текст, перевести его и стереть надписи вместе с
дорисовкой фона под ними — всё на своём компьютере.

WinUI 3, C#, .NET 10, без установщика. Спецификация — [SPEC.md](SPEC.md),
аудит кода против неё — [AUDIT-m6.md](AUDIT-m6.md).

---

## Быстрый старт

```bash
dotnet publish src -c Release -r win-x64 -o out
out\gallery.exe D:\foto
```

Папку можно открыть аргументом, `Ctrl+Shift+O` или перетаскиванием на окно.

## Что умеет

### Просмотр

* Листание папки без задержек: смена кадра из кэша — 0,1 мс, вокруг текущего
  держится префетч, при быстром листании лишние декодирования отменяются.
* JPEG, PNG, WebP, BMP, GIF, TIFF, HEIC (если в системе есть кодек), включая
  прогрессивный JPEG и файлы на 24 мегапикселя.
* EXIF-поворот и управление цветом применяются при декодировании.
* Зум к курсору, панорамирование мышью и с клавиатуры, «вписать» и «1:1».
* Полноэкранный режим, тёмная, светлая и высококонтрастная темы.
* Объявления скринридеру на каждое действие.
* Битый, пустой или слишком широкий файл не роняет приложение, а показывает
  внятную заглушку.

### Отбор по папкам

* Девять независимых слотов-назначений на цифрах `1`…`9`; `Space` — слот 1.
* Первое нажатие на непривязанный слот спрашивает папку и тут же копирует —
  нажатие не теряется.
* Копирование идёт очередью в фоне, интерфейс не ждёт диск.
* Повторное копирование того же файла безопасно: тот же файл — ничего не
  происходит, чужой файл с тем же именем — копия получит суффикс.
* `Ctrl+Z` отменяет последнее копирование, файл уходит в Корзину.
* Уже скопированные кадры помечаются в ленте и в счётчике — сверка идёт по
  размеру и содержимому, а не по имени.
* Закрыть окно с непустой очередью нельзя без подтверждения.

### Папки

* Обход рекурсивный, до 8 уровней и 20 000 кадров: том комикса, разложенный по
  главам, читается подряд. Целевые папки копирования из обхода исключаются.
* Позиция запоминается для **каждой** папки отдельно.
* `F7` — список недавних папок с запомненным кадром в каждой; исчезнувшие строки
  отсеиваются при открытии списка.
* `F5` — пересканировать. Папка перечитывается и сама, когда файлы в ней меняются.

### Лента миниатюр

`T` или `F6`. Текущий кадр всегда в центре, колесо над лентой листает, щелчок —
переход. Положение (снизу или справа) и непрозрачность — в настройках.

### Распознавание текста — `F4`

PP-OCRv5 на ONNX Runtime, локально. Строки сшиваются в реплики по детектору
облаков текста (RT-DETRv2), поэтому «WHY AM I ALWAYS» и «THE ONLY ONE ON TIME…»
остаются одной фразой, а не двумя обрывками. Слой показывает, что именно
распозналось и как сгруппировалось.

### Перевод страницы — `F2`

* **На этом компьютере** — Marian opus-mt-en-ru на CPU. Веса (425 МБ) не входят
  в поставку и скачиваются по требованию в `%LOCALAPPDATA%\Gallery\models`.
* **Через API** — страница уходит одним запросом целиком, поэтому род и
  обращение «ты/вы» согласованы по всему диалогу. Адрес совместим с форматом
  OpenAI: подойдёт любой поставщик или локальный сервер. Ключ хранится отдельно
  от настроек и шифруется на вашу учётную запись Windows.
* Перевод рисуется поверх страницы на подложке, цвет которой взят из самого
  пузыря, а кегль — из шага строк на странице.
* `F3` — журнал запросов к API: что ушло, что пришло, сколько заняло.

### Очистка страницы от текста — `F8`

Три шага, нарочно разделённые: стирание необратимо по смыслу, и увидеть
пропущенную букву можно только **до** дорисовки.

1. **Найти текст** — где на странице надписи. Источников два: сегментатор букв
   (Unet/resnet18) и рамки распознавания; поодиночке каждый молчит на части
   кадров. Найденные куски сводятся в надписи по их собственной высоте — по
   одной рамке на надпись, вложенные убираются, налезающие разводятся.
2. **Разметить буквы** — какие пиксели внутри рамок действительно буквы.
   Розовым показано, что уйдёт под стирание.
3. **Дорисовать** — LaMa (`lama-manga`) восстанавливает фон под разметкой.

Дальше — ручная доводка:

* **Кисть и ластик** правят разметку; вокруг курсора видно её размер, размеры
  кисти и ластика помнятся порознь.
* **Залить градиентом** — для гладкого фона: гармоническая заливка считает цвета
  по краям дыры и выводит настоящий градиент, без однотонного шлейфа. 225 мс
  против секунд у сети.
* **Рисование по кадру** — пипетка, карандаш, линия, квадрат, круг. Цвет берётся
  из самого кадра, край мазка смягчён. Нужно, когда сеть обрезала линию: ни одна
  из проверенных моделей (LaMa, big-LaMa, MI-GAN, EdgeConnect, Telea, Navier) не
  продолжает линию в область, где её ничто не подсказывает, — проще дорисовать
  самому.
* Работа **по блоку**: разметить, дорисовать, залить, убрать рамку, убрать
  разметку — только в выбранном. Края и углы рамки тянутся мышью.
* **Отмена на 12 шагов** вперёд и назад; при выбранном блоке отменяется только
  он, остальные остаются.
* `F1` (держать) — показать исходник для сравнения.
* `Ctrl+S` — сохранить рядом как `имя-clean.png`, `Ctrl+Shift+S` — перезаписать
  оригинал в его же формате.

### Настройки — `Ctrl+,`

Целевые папки слотов, тема, способ перевода и параметры API, лента миниатюр
(показывать, положение, непрозрачность), «после копирования — следующий кадр»,
«пробел листает, а не откладывает». Без кнопок ОК/Отмена — всё применяется сразу.

### Отладка

`F12` — счётчики производительности поверх кадра. Ошибки пишутся в
`%LOCALAPPDATA%\Gallery\logs`.

## Модели

Три модели лежат рядом с исполняемым файлом, в `out\models`. В репозиторий они не
входят — 263 МБ бинарников; положите их в `src\models`, сборка скопирует сама.

| Файл | Что делает | Размер | Лицензия |
|---|---|---|---|
| `comic-bubbles.onnx` | облака текста, RT-DETRv2 (`ogkalu/comic-text-and-bubble-detector`) | 11 МБ | Apache-2.0 |
| `comic-text-mask.onnx` | разметка букв, Unet/resnet18 (`TareHimself/comic-text-mask`) | 55 МБ | MIT |
| `lama-manga.onnx` | дорисовка фона под стёртым текстом | 197 МБ | — |
| `models\v5\*` | PP-OCRv5: детектор, классификатор, распознаватель | ~10 МБ | Apache-2.0 (едет в пакете RapidOcrNet) |

Веса локального переводчика (Marian opus-mt-en-ru, 425 МБ) скачиваются по
требованию в `%LOCALAPPDATA%\Gallery\models\opus-mt-en-ru`.

## Командная строка

| | |
|---|---|
| `gallery.exe D:\foto` | открыть папку или файл |
| `gallery.exe --self-test` | самопроверка, отчёт в `%LOCALAPPDATA%\Gallery\self-test.txt` |
| `gallery.exe --page стр.jpg` | весь тракт распознавания и перевода без окна; `--api` — через API, `--legacy` — запасным движком. Отчёт в `page.txt` |
| `gallery.exe --clean папка` | очистка от текста пакетом: рядом с каждым файлом ложатся `-mask` и `-clean`, отчёт в `clean.txt` |
| `gallery.exe --translate …` | перевод без окна |
| `gallery.exe D:\foto --bench 200 33` | замер горячего пути: шагов и интервал в мс. Отчёт в `bench.csv` |
| `gallery.exe --bench-decode testdata` | замер декодирования, отчёт в `bench-decode.md` |
| `gallery.exe --startup-probe` | время до первого отрисованного кадра, строка в `startup.csv` |

Все отчёты пишутся в `%LOCALAPPDATA%\Gallery`.

## Проверки

```bash
out\gallery.exe --self-test
```

396 проверок вместо тестового проекта: геометрия рамок и блоков, группировка
надписей, гармоническая заливка, рисование, порядок чтения, разбор ответов API,
натуральная сортировка, поиск дубликатов, вёрстка подложек.

Тестовый корпус генерируется:

```bash
python tools/gen-testdata.py
```

20 файлов в `testdata/`: 24 МП baseline и прогрессивный JPEG, все варианты
EXIF-ориентации, PNG 24 МП, битые и пустые файлы, панорама шире лимита текстуры,
Unicode и bidi-спуфинг в именах. В репозиторий не входят — генерируются.

Пробные страницы для распознавания и очистки лежат в `corpus/`, `comicstest/`,
`ocrtest/`, шрифты для генератора — в `fonts/`.

## Сборка

```bash
dotnet publish src -c Release -r win-x64 -o out
```

Один файл для раздачи:

```bash
dotnet publish src -c Release -r win-x64 -p:PublishSingleFile=true -p:IncludeAllContentForSelfExtract=true -o out-single
```

`PublishReadyToRun` включён в csproj и **обязателен**: без него холодный старт
1683 мс вместо 885 (§2.4 спецификации).

Нужен .NET SDK 10. Visual Studio не нужна, шаблоны WinUI не нужны.
